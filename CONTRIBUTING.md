# Contributing

This repository is a collection of simple skills for AI tools.

## Add a new skill

1. Create a folder under `skills/` with a snake_case name.
2. Add a `SKILL.md` file. Write it in clear, short sentences.
3. Add a short description in the main README table.
4. Do not include personal information in any public file.

## Style rules

- Use short sentences.
- Use simple words.
- Write for people who are not technical.
- Always include a guided setup section if the skill needs user data.
