# Security policy

## Report a problem

Do not report security problems in a public issue.

1. Open the **Security** tab of this repo.
2. Click **Report a vulnerability**.
3. Describe the problem and the steps to see it.
4. Click **Submit report**.

The report stays private. Only the maintainers can see it.

Direct link: https://github.com/ev-llh/Skillful-Grok/security/advisories/new

## Personal data

This repo is public. If you find personal data in a file, report it with the steps above.

## Supported versions

The `main` branch gets fixes.
